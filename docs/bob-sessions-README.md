# bob_sessions

IBM Bob task session summary screenshots for CVE Autopilot by Team Diapers (required for submission).

How to capture (from the hackathon guide): Bob IDE chat → **Tasks** → open the task → click the
**task header** → screenshot the task session consumption summary. Save as PNG.

File name: `diapers_<member>_task<NN>_<short-description>_summary.png`, e.g.

- `diapers_pafras_task01_plan_remediation_summary.png`
- `diapers_erin_task01_architecture_readme_summary.png`
- `diapers_dyan_task01_streamlit_app_summary.png`

Every member uploads screenshots of all their tasks for this project.
Before adding a file, check it shows no API keys, passwords or tokens.
